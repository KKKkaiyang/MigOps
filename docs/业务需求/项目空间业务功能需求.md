# 迁移管家（MigOps）项目空间业务功能需求 — 概览、项目资料索引、数据迁移与任务迁移

> 文档版本：V1.1 ｜ 编写日期：2026-10-22 ｜ 状态：需求确认版（§8.2 默认项已评审确认）
> 适用范围：项目空间内业务模块——概览页（项目空间 Panel 入口）、项目资料索引（`b02`）、数据迁移管理（`b03`）、任务迁移管理（`b04`，含自定义台账）
> 配套文档：根目录 [`CODEBUDDY.md`](../../CODEBUDDY.md)（开发规范）、`docs/业务需求/迁移管家平台-业务需求文档.html`（平台总 BRD，下称"BRD"）、`docs/业务需求/公共业务-用户权限与项目空间管理需求.md`（用户/权限/空间基座，下称"公共业务需求"）

## 1. 概述

### 1.1 背景与目标
迁移管家以「迁移空间」为隔离单元管理大数据迁移全流程。用户登录后的**概览页**需要一眼看到自己权限下的全部项目，并能快速进入空间开展工作；空间内则需要把项目资料、数据迁移、任务迁移三类核心台账线上化。

本需求在上位文档基础上完成四项落地定义：

- **概览页项目 Panel**：以面板形式展示权限内所有项目，提供「进入空间」快捷入口；
- **项目资料索引（b02）**：集中维护外部链接、Markdown 资料与平台内台账入口，其中 Markdown 资料支持编辑器编辑、渲染查看、本地下载与可选密码保护；
- **数据迁移管理（b03）**：按迁移场景管理库表清单的元数据/全量/增量迁移状态与迁移过程记录；
- **任务迁移管理（b04）**：按迁移场景管理任务全生命周期状态、排查备注时间线与自定义台账。

### 1.2 范围
| 模块 | 归属 | 本期范围 |
| --- | --- | --- |
| 概览页（项目空间 Panel） | 前端首页 `/` | 项目 Panel 区、进入空间、空间视图框架 |
| 项目资料索引 | `b02_` 表（空间库） | 资料 CRUD、分类管理、Markdown 编辑/查看/下载/密码 |
| 数据迁移管理 | `b03_` 表（空间库） | 迁移场景、库表清单、迁移状态、迁移过程记录、导入导出 |
| 任务迁移管理 | `b04_` 表（空间库） | 迁移场景、任务台账、状态流转、排查备注、自定义台账 |

**不在本期范围**（后续迭代或见其他文档）：

- 用户、角色、权限与空间创建/成员管理：见《公共业务需求》；
- 数据校验管理（`b05`）、统计看板、标签管理（`b04` 依赖的标签打标/筛选）：二期；
- 自定义台账的**标签组合筛选**：待二期标签管理上线后扩展，本期仅支持属性筛选组合。

### 1.3 术语
| 术语 | 含义 |
| --- | --- |
| 概览页 | 登录后首页 `/`，本需求在其主体最上方新增「我的项目空间」Panel 区 |
| Panel | 概览页中单个项目的展示面板（卡片），右下角含「进入空间」按钮 |
| 项目空间视图 | 进入空间后的工作区页面（空间概览 + 模块导航），路由形如 `/space/:spaceId` |
| 迁移场景 | 数据迁移/任务迁移下的分组单元（如 `hive 元数据迁移`、`hive→hive`），各场景独立管理台账 |
| 自定义台账 | 在任务迁移场景中保存的筛选视图，数据引用原任务台账（非副本） |

## 2. 总体交互框架

### 2.1 页面层级与路由
```
概览页（/）
  └─ 我的项目空间 Panel 区（权限内全部项目）
       └─ 点击「进入空间」→ 项目空间视图（/space/:spaceId）
            ├─ 空间概览（空间信息 + 模块导航入口）
            ├─ 项目资料索引（/space/:spaceId/materials）
            ├─ 数据迁移管理（/space/:spaceId/data-migrations）
            └─ 任务迁移管理（/space/:spaceId/tasks）
                 └─ 自定义台账视图（/space/:spaceId/tasks/views/:viewId）
```
- 路由 `name` 采用 kebab-case，遵循 `CODEBUDDY.md` §4.2；
- 后端接口前缀 `/api/v1/b02`、`/api/v1/b03`、`/api/v1/b04`，遵循 §4.1；
- 空间视图头部常驻空间基本信息与模块导航，模块页在导航区切换。

### 2.2 权限模型
沿用《公共业务需求》三级角色，本需求不重复定义：

- **可见范围**：概览 Panel 区展示当前用户权限内的全部空间（L0 看全部；L1/L2 看被加入的空间）；
- **空间信息编辑（含整体进展维护）**：仅 L0 / L1；
- **空间内业务操作（资料、数据迁移、任务迁移）**：L0 / L1 / L2 均可；
- 各页面按角色控制按钮可见性（创建、编辑、删除、状态流转等），越权请求由后端 `Depends` 依赖统一拦截。

## 3. 概览页 — 我的项目空间 Panel 区

> 原型参考：BRD《8.1 项目空间列表》；交互在原型基础上按本章节细化。

### 3.1 页面布局
1. Panel 区位于概览页**主体最上方**（既有平台 Banner 与流程说明内容保留在 Panel 区下方，避免既有信息丢失）；
2. Panel 采用网格排布（建议三列，窄屏自适应降列），一个空间一个 Panel；
3. Panel 区工具栏：项目名称/简称**搜索框**、空间状态筛选（全部/初始化/交付中/已验收）、「+ 创建迁移空间」按钮（**仅 L0/L1 可见**，复用现有空间创建能力，弹窗创建）；
4. 空态：无权限空间时展示引导——L0/L1 显示「创建迁移空间」按钮；L2 提示「暂无加入的空间，请联系项目管理员」。

### 3.2 Panel 展示内容
| 展示项 | 字段来源 | 说明 |
| --- | --- | --- |
| 项目名称 | `space_name` | Panel 标题，加粗 |
| 项目简称 | `space_code` | 标题下方次要文本 |
| 项目空间说明 | `remark` | 次要文本，超长两行截断（悬浮展示全文） |
| 源端平台 → 目标端平台 | `source_platform` / `target_platform` | 形如「华为云 → 腾讯云」 |
| 空间状态 | `status` | 标签展示：初始化 / 交付中 / 已验收 |
| 整体进展 | `overall_progress`（**本期新增字段**，见 §3.4） | 进度条 + 百分比，如 68% |
| 我的角色 | 空间角色关系 | 当前用户在该空间内的角色（L0/L1/L2） |
| 成员数 | 空间成员关系计数 | 形如「成员 8 人」 |
| 最近更新 | `updated_at` | 形如「最近更新：2026-10-05」 |

### 3.3 进入空间
- 每个 Panel **右下角**固定「进入空间」按钮（主色按钮）；
- 点击跳转项目空间视图 `/space/:spaceId`（默认落地空间概览）；
- 无权限访问他人空间时，由后端权限依赖拦截并提示。

### 3.4 基础表字段补充（`b01_space`）
现有实现（`code/backend/app/models/space.py`）已具备客户名称、源/目标端平台、项目起止日期、项目空间说明等字段，与 BRD 6.1 数据字段对齐。本需求**唯一需新增的字段**：

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `overall_progress` | TINYINT | 非空，默认 0，取值 0~100 | 项目整体进展（百分比），**手工维护**，见 §3.5 |

> 说明：空间列表接口（`GET /api/v1/b01/spaces`）需同步返回 `overall_progress` 与成员数 `member_count`，供 Panel 区渲染；`member_count` 由成员关系聚合计算，不落库。

### 3.5 项目整体进展维护（手工）
- **维护入口**：空间信息编辑（现有空间创建/编辑表单），新增「整体进展」录入项（0~100 整数，滑块或数字输入均可）；
- **维护权限**：L0 / L1（与空间信息编辑权限一致）；
- **展示位置**：概览页 Panel、项目空间视图头部；
- **后续演进**：本期按需求要求**手工维护**；二期可切换为按任务完成率自动计算（切换时需保留手工覆盖能力，评审时确认）。

### 3.6 功能清单
| 功能项 | 描述 | 优先级 | 来源 |
| --- | --- | --- | --- |
| 项目 Panel 展示 | 按权限拉取空间列表，以 Panel 网格展示 §3.2 字段 | P0 | BRD F6.1.4 增强 |
| Panel 搜索与筛选 | 按项目名称/简称搜索，按空间状态筛选 | P0 | BRD 原型 8.1 |
| 创建迁移空间入口 | 工具栏创建按钮（L0/L1 可见），复用现有创建能力 | P0 | BRD F6.1.1 |
| 进入空间 | Panel 右下角按钮跳转项目空间视图 | P0 | 本次新增 |
| 整体进展维护 | 空间信息编辑中手工维护 0~100 | P0 | 本次新增 |
| 项目空间视图框架 | 空间头部信息 + 模块导航（资料索引/数据迁移/任务迁移） | P0 | 本次新增 |
| 空态引导 | 无空间时的创建/联系管理员引导 | P1 | 本次新增 |

## 4. 项目资料索引（b02）

> 原型参考：BRD《8.2 项目资料索引》；功能基线为 BRD F6.2.1~F6.2.6，本需求在其上细化类型码值与 Markdown 能力。

### 4.1 功能概述
集中维护项目内各类台账与资料，按分类分组展示。资料分三种**类型**：外部链接、Markdown、平台台账。

### 4.2 资料类型（码值）
| 类型 | 码值 | 必填内容 | 行为 |
| --- | --- | --- | --- |
| 外部链接 | `external_link` | 链接地址（URL） | 列表中「打开」新标签页跳转外部地址 |
| Markdown | `markdown` | Markdown 原文（`content`） | 编辑器编辑、渲染查看、下载 `.md`、可选密码保护（§4.4） |
| 平台台账 | `platform_ledger` | 跳转目标模块 | 跳转至空间视图内对应模块（数据迁移管理 / 任务迁移管理），预置目标随模块扩展补充 |

- 原 BRD 中「链接类型」字段统一更名为**「类型」**，上述三种码值为全集；
- 平台台账类型解决"平台内模块快捷入口"诉求（如工作量登记台账、数据源清单、任务代码清单等条目），一期预置可跳转数据迁移管理与任务迁移管理两个已实现模块。

### 4.3 列表与分类
1. 按分类分组展示（原型顺序：项目管理类 → 调研资料类 → 代码与迁移类），每条展示资料名称、类型标签、更新时间、维护人；
2. 操作列：查看/打开（按类型）、编辑、删除（L0/L1/L2 均可维护资料，删除需二次确认）；
3. 分类管理：预置三类分类，支持自定义分类的增改；删除分类时其下资料置为「未分类」，不删除资料；
4. 排序：本期按更新时间倒序 + 手动置顶（`sort_no`）；拖拽排序二期（BRD F6.2.6 降级）。

### 4.4 Markdown 资料
#### 4.4.1 编辑与查看
- **编辑**：使用 Markdown 编辑器组件（选型 **`md-editor-v3`**，已评审确认，见 §8.1 D7），支持源码/分屏/预览模式，**不使用富文本框**；
- **查看**：列表中「查看」打开只读渲染视图（Markdown 渲染结果 + 工具栏：下载、关闭），同样基于 Markdown 渲染组件，非富文本；
- 编辑入口对空间成员开放（编辑免密，见 §4.4.3）。

#### 4.4.2 下载
- 查看态工具栏与列表行操作均提供「下载」；
- 下载得到 UTF-8 编码的 `<资料名称>.md` 文件，内容为 Markdown 原文；
- 文件名需做净化处理（防路径分隔符、控制字符与响应头注入）。

#### 4.4.3 密码查看（敏感资料保护）
| 项 | 规则 |
| --- | --- |
| 设置 | 创建/编辑 Markdown 资料时，「查看密码」**选填**，默认不设置（即无需密码） |
| 修改/清除 | 编辑资料时可修改或清除密码 |
| 存储 | `view_password_hash`（bcrypt 哈希，复用平台 `app/core/security` 哈希工具）；NULL = 无需密码；**禁止明文存储** |
| 校验范围 | **查看内容、下载文件需验证密码；编辑免密**（维护人可信，避免维护受阻） |
| 校验交互 | 点击查看/下载时弹出密码输入框，错误时提示「密码错误」；验证通过后**当前会话内不再重复提示**（前端内存态，刷新后失效） |
| 失败策略 | 同一资料查看密码**连续 5 次错误锁定 10 分钟**（`view_pwd_locked_until` 到期自动解锁；验证成功清零失败计数）；锁定期间拒绝验证并提示剩余时间 |

### 4.5 数据模型（空间库 `mig_<space_code>_db`）
#### 4.5.1 资料分类表（`b02_category`）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | BIGINT | PK，自增 | 主键 |
| `space_id` | BIGINT | 非空 | 所属空间 |
| `name` | VARCHAR(64) | 非空 | 分类名称 |
| `sort_no` | INT | 默认 0 | 展示排序 |
| `is_preset` | TINYINT | 默认 0 | 是否预置分类（预置不可删除） |
| 审计字段 | — | 必填 | `created_by` / `created_at` / `updated_by` / `updated_at` / `deleted_at` |

#### 4.5.2 资料索引表（`b02_material`）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | BIGINT | PK，自增 | 主键 |
| `space_id` | BIGINT | 非空 | 所属空间 |
| `category_id` | BIGINT | 可空 | 分类；NULL = 未分类 |
| `name` | VARCHAR(255) | 非空 | 资料名称 |
| `type` | VARCHAR(32) | 非空 | 类型：`external_link` / `markdown` / `platform_ledger` |
| `url` | VARCHAR(1024) | 可空 | 外部链接地址（`external_link` 必填） |
| `target_module` | VARCHAR(64) | 可空 | 平台台账跳转目标模块（`platform_ledger` 必填） |
| `content` | LONGTEXT | 可空 | Markdown 原文（`markdown` 必填） |
| `view_password_hash` | VARCHAR(255) | 可空 | 查看/下载密码哈希；NULL = 无需密码 |
| `view_pwd_fail_count` | INT | 默认 0 | 查看密码连续失败计数（验证成功清零） |
| `view_pwd_locked_until` | DATETIME | 可空 | 密码验证锁定截止时间；NULL = 未锁定 |
| `description` | VARCHAR(512) | 可空 | 描述信息 |
| `sort_no` | INT | 默认 0 | 排序；置顶资料设为较大值 |
| 审计字段 | — | 必填 | `created_by` / `created_at` / `updated_by` / `updated_at` / `deleted_at` |

## 5. 数据迁移管理（b03）

> 原型参考：BRD《8.3 数据迁移清单》；功能基线为 BRD F6.3.1~F6.3.10。

### 5.1 功能概述
按迁移场景管理库表清单，维护每张表的元数据迁移状态、全量/增量迁移状态与数据截止日期，并记录每次迁移的过程明细，形成迁移历史。

### 5.2 功能要点
1. **迁移场景**：空间下可创建多个场景（如 `hive 元数据迁移`、`hbase 数据迁移`），场景间数据隔离，支持场景的新增/重命名/删除（删除需二次确认，级联处理其下清单）；
2. **库表清单**：支持 Excel/CSV 导入（字段：库名、表名、目标库名、目标表名、表类型、预估数据量、分区数），支持重复导入更新；提供模板下载；
3. **状态维护**：元数据状态（未迁移/迁移中/已完成/异常）、全量迁移状态（未迁移/迁移中/已完成/异常）+ 全量迁移截止日期、增量迁移状态（未开始/进行中/已停止/异常）+ 最新同步时间；支持单个与**批量**更新、批量标注截止日期；
4. **迁移过程记录**：每次迁移生成一条记录（迁移类型、起止时间、数据量、迁移方式、数据截止日期、状态、备注），支持手工补录与 Excel 批量导入；清单行展示记录数，点击展开该表迁移历史（原型 8.3 下方记录区）；
5. **筛选与导出**：按库名/表名/表类型/各状态筛选；导出当前场景清单及状态为 Excel；
6. 操作留痕：状态变更与记录补录写入审计字段（`updated_by` / `updated_at`）。

### 5.3 数据模型（空间库）
#### 5.3.1 迁移场景表（`b03_scenario`）
| 字段 | 类型 | 约束 | 说明 |

## 6. 任务迁移管理（b04）

> 原型参考：BRD《8.4 任务迁移台账》；功能基线为 BRD F6.4.1~F6.4.10 与 F6.6.1~F6.6.6（自定义台账）。

### 6.1 功能概述
按迁移场景管理任务台账，覆盖任务从改造、调度、校验到验收的全生命周期状态；支持排查备注时间线沉淀问题处理过程；支持将筛选条件保存为**自定义台账**（引用视图）。

### 6.2 功能要点
1. **迁移场景**：空间下可创建多个场景（如 `hive→hive`、`holo→starrocks`、`maxcompute→dlc`），场景间数据隔离；
2. **导入任务台账**：Excel/CSV 导入（字段：工作流名称、任务名称、脚本名称、Owner、迁移状态、调度状态、数据校验状态、输入表、输出表），支持**覆盖导入与增量导入**两种模式，提供模板下载；导入时系统自动生成任务 URI（`项目名称://任务名称@工作流名称`，空间内唯一）；
3. **台账列表**：表格展示核心字段，支持分页、排序、列显隐；行操作进入详情；
4. **状态流转**：单个/批量更新迁移状态，流转需符合 BRD 4.2 状态机（未开始 → 改造完成 → 调度成功 → 数据校验通过/不通过 → 客户验收通过/不通过；挂起/废弃为旁路态），非法流转前端提示、后端拦截；
5. **筛选**：按任务名称、工作流、迁移状态、调度状态、校验状态、Owner 组合筛选；**标签筛选与标签列二期实现**（标签管理不在本期，见 §1.2）；
6. **任务详情**：展示任务全部字段、状态变更历史、排查备注时间线（§6.3）；
7. **排查备注**：详情内添加，多条记录形成时间线；支持校验结果类备注；
8. **自定义台账**（§6.4）：保存筛选条件形成引用视图；
9. **导出**：当前筛选结果导出 Excel，与页面展示一致。

### 6.3 排查备注时间线
每条记录包含：备注时间、备注人、备注类型（排查备注 / 校验结果）、问题描述、原因分析、修复方案（排查类必填问题描述，其余选填）。时间线按时间正序展示，最新在下；不可删除（审计完整性），可追加补充备注。

### 6.4 自定义台账（本期实现）
1. 在任务台账列表设置筛选条件（**本期仅属性筛选组合：工作流/状态/Owner/任务名称等**）后，通过「保存为台账」创建，填写台账名称与描述；
2. 自定义台账列表在场景下展示，点击进入台账视图；
3. **数据引用**：台账数据引用原任务记录，非副本；原任务更新后台账同步更新（单一真实来源）；
4. 台账视图内支持对任务进行状态更新等操作，结果同步回原台账；
5. 支持编辑台账筛选条件与名称、删除台账（仅删视图）；
6. 标签组合筛选能力预留（`filter_config` JSON 结构预留标签维度），待二期标签管理上线后开启。

## 7. 安全与质量约束

1. **Markdown 渲染防 XSS**：查看态渲染必须经 DOMPurify（或等价净化库）净化后再注入 DOM，禁止直接 `v-html` 原始内容；
2. **密码安全**：查看密码仅存 bcrypt 哈希（复用 `app/core/security`），禁止明文存储与日志打印；
3. **下载安全**：`.md` 文件名净化（去除路径分隔符、控制字符，限制长度），防头注入与路径穿越；
4. **审计**：所有业务表遵循 `CODEBUDDY.md` §3.3 审计字段；状态流转、删除、密码变更记录操作人与变更前后；
5. **统一响应与分层**：接口统一响应结构 `{ code, message, data, trace_id }`；router → service → repository → model 分层，跨层 Pydantic Schema 传递（`CODEBUDDY.md` §5）；
6. **导入安全**：Excel/CSV 导入需校验文件类型与大小上限，解析失败给出明确行级错误提示。
