## 1. 概述

### 1.1 背景与目标
任务迁移列表页（及台账视图）的「标签」列已支持展示任务所带的多个标签（色块 + 文字胶囊，圆角 `10px`、字号 `11px`），并支持内联 `+` 打标与 `×` 去标（见「标签管理与标签化台账需求」§3.2 / §3.5）。

但在实际使用中，单任务可能被打上较多标签，导致「标签」列横向被拉得很长、行高被撑高，既挤压其他列（任务 / 工作流 / Owner / 各状态列）的展示空间，也使列表整体密度下降、可读性变差。

本需求在不改变标签数据、不打断既有打标/去标能力的前提下，对「标签」列增加**溢出折叠**能力：一行标签数量超过阈值时自动折叠，仅展示前 N 个，并以「V 下三角」按钮露出剩余数量，点击展开全部、再点收起，保持列表行高平稳、信息密度合理。

### 1.2 范围
| 能力 | 归属 | 本期范围 |
| --- | --- | --- |
| 标签列溢出折叠 | `b04`（前端展示） | 任务迁移列表页 + 台账视图「标签」列，标签数超阈值时折叠为「前 N 个 + 展开按钮」 |
| 展开 / 收起切换 | `b04`（前端展示） | 点击「V」展开全部并显示「^ 收起」，再次点击收起；折叠态展示剩余数量 |
| 内联打标 / 去标可用 | `b04`（前端展示） | 折叠态行尾 `+` 打标入口始终可见；展开态各标签 `×` 就地去标，与现状一致 |

**不在本期范围**：
- 标签数据模型、标签管理模块、按标签筛选、内联打标浮层逻辑（均沿用「标签管理与标签化台账需求」，本需求只改展示层）；
- 后端接口 / 库表变更（标签数据已由任务列表接口 `tags[]` 返回，本次纯前端渲染优化，无新增 API / DDL）；
- 折叠阈值的用户自定义配置（本期为前端常量，默认 3，见 D2）。

### 1.3 术语
| 术语 | 含义 |
| --- | --- |
| 标签列 | 任务迁移列表页 / 台账视图表格中的「标签」列，渲染任务所带标签（来自 `b04_task_tag`）为胶囊 |
| 折叠态 | 标签数量超过阈值时，仅展示前 N 个标签 + 「V 展开(N)」按钮的收起状态 |
| 展开态 | 点击展开按钮后，展示该任务全部标签 + 「^ 收起」按钮的状态 |
| 阈值 N | 折叠触发数量，默认 3（见 D2）：标签数 ≤ N 不折叠、完整展示；> N 折叠 |

## 3. R-01 任务列表标签列溢出折叠与展开

### 3.1 功能描述
对任务迁移列表页（`space-tasks`）与台账视图（`SavedViewList` / 台账详情页）共用的「标签」列组件，增加溢出折叠能力：当某行任务所带标签数量 **> 阈值 N（默认 3）** 时，默认进入折叠态，仅渲染前 N 个胶囊，其后以「V 展开(N)」按钮收口；点击展开全部标签并显示「^ 收起」；再次点击或点击「^ 收起」回到折叠态。

标签数量 **≤ N** 时行为与现状完全一致：完整渲染全部标签胶囊，不显示展开/收起按钮。

### 3.2 交互与界面
- **入口位置**：任务迁移列表页「标签」列、台账视图「标签」列（两处复用同一列渲染组件，保证行为一致）。
- **折叠态（标签数 > N）**：
  - 渲染前 N 个标签胶囊（沿用 §6.4.2 胶囊样式：圆角 `10px`、字号 `11px`、色块 + 文字）；
  - 其后紧跟一个「V 展开(N)」文本按钮（N = 剩余隐藏标签数），下三角 `▼` 图标 +「展开 N」或「展开」文案；
  - 行尾「+」打标图标**始终可见**（见 R-02 / D4）。
- **展开态（点击 V 后）**：
  - 渲染该任务**全部**标签胶囊；
  - 每个标签胶囊右侧「×」可就地去标（见 R-02 / D4）；
  - 末尾显示「^ 收起」文本按钮（上三角 `▲` 图标 +「收起」文案）。
- **切换行为**：折叠态 ↔ 展开态双向切换，均为行内局部展开，**不影响其他行**；切换不触发列表重拉、不丢失筛选/分页状态。
- **视觉令牌**（沿用 `CODEBUDDY.md` §6.4）：
  - 展开/收起按钮文字采用弱化文本色（`#8a96a3` / `#9aa7b5`），字号 `12px`，hover 主色 `#1a73e8`，无边框轻按钮样式；
  - 三角图标 `▼` / `▲` 与文案同色，圆角 `4px`（状态小点/小按钮级），点击区不小于 `20px` 高。

### 3.3 权限与可用性
- **适用角色**：所有可见任务列表的角色（L0/L1/L2），纯展示交互，与既有列表权限一致；打标/去标权限沿用「标签管理与标签化台账需求」D6（L0/L1/L2 均可）。
- **与其他能力的关系**：复用既有「标签」列组件；叠加在「标签管理与标签化台账需求」的标签渲染与内联打标之上，**不改动**标签数据、标签管理模块、按标签筛选、内联打标浮层逻辑。

### 3.4 后端接口 / 数据变更
**无。** 本次为纯前端展示优化：
- 任务列表接口 `GET /b04/scenarios/{id}/tasks` 已返回 `tags[]`（含 id/name/category/color），折叠/展开仅在前端按 `tags.length` 与阈值 N 计算，不需要后端配合；
- 无新增 API、无 DDL、无状态机变更；内联打标/去标仍复用既有 `PUT /tasks/{id}/tags` 等接口。

## 4. R-02 内联打标 / 去标在折叠态与展开态均可用

### 4.1 功能描述
确保标签列的溢出折叠**不破坏**既有的内联打标 / 去标能力（见「标签管理与标签化台账需求」§3.2）：

- **折叠态**：行尾「+」打标图标始终显示，点击弹出已创建标签多选浮层（按分类分组），选中即就地打标；折叠态下胶囊数量受 N 限制，但「+」入口不受隐藏影响；
- **展开态**：每个标签胶囊上「×」可就地去标，点击后实时移除该标签（与前一致）；
- 打标 / 去标成功后，标签列按实时结果重新计算折叠态（标签数变化可能使某行由折叠变完整、或反之），沿用 A12 实时刷新原则（不整页刷新）。

### 4.2 交互与界面
- 「+」图标位置：标签列行尾常驻（折叠态与展开态均可见），样式沿用既有内联打标图标；
- 「×」图标位置：每个标签胶囊右上/右侧，展开态可见；
- 操作后无需手动刷新（A12）。

### 4.3 权限与可用性
同 §3.3；打标/去标权限沿用 D6。

## 5. 非功能性约束

### 5.1 统一响应与分层（沿用 CODEBUDDY.md §5）
无后端改动；若后续将该交互抽为公共组件，须置于 `components/common` 或任务列表组件内，沿用 router → service → repository → model 分层外的纯前端渲染逻辑。

### 5.2 界面视觉（沿用 CODEBUDDY.md §6.4）
- 标签胶囊严格采用 §6.4.2 样式（圆角 `10px`、字号 `11px`、色块 + 文字），不引入第二套配色；
- 展开/收起按钮采用弱化文本色 + 主色 hover，三角图标 `▼`/`▲`，圆角 `4px`，与列表整体视觉一致；
- 折叠/展开切换为行内局部行为，不引起列表跳动或列宽突变（阈值 N 控制单行标签占用宽度上限）。

### 5.3 其他约束
- **无性能 / 安全新增风险**：纯前端渲染，不引入额外请求；
- **一致性**：任务迁移列表页与台账视图复用同一「标签」列组件，保证两处折叠/展开行为完全一致（D1）。

| 编号 | 验收项 | 通过条件 |

| R-01 | 折叠触发 | 任务带标签数 > 阈值 N（默认 3）时，该行列默认折叠，仅显示前 N 个 + 「V 展开(N)」；≤ N 时完整显示、无展开按钮 |
