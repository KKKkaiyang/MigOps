# 迁移管家（MigOps）任务迁移 — 标签管理与标签化台账需求

> 文档版本：V1.1 ｜ 编写日期：2026-10-23 ｜ 状态：需求确认版（§8 决策已交互确认；V1.1 含本次优化迭代）
> 适用范围：任务迁移管理（`b04`）的标签体系与标签化台账——在既有「自定义台账」（`b04_saved_view`，动态引用视图）基础上，新增**空间级标签管理（独立模块）**、**任务打标签/按标签筛选（含内联 + 号打标）**、并将自定义台账升级为支持「固化台账」模式
> 配套文档：`docs/业务需求/项目空间业务功能需求.md`（上位需求，本需求扩展其 §6 `b04` 标签维度）、`docs/业务需求/任务迁移-在线文档导入与同步刷新需求.md`（导入来源增强）、`docs/业务需求/迁移管家平台-业务需求文档.html`（平台总 BRD）、根目录 `CODEBUDDY.md`（开发规范，§3.2 预留 `b06_` 标签管理）

## 1. 概述

### 1.1 背景与目标
任务迁移台账（上位需求 §6 `b04`）当前已具备：场景管理、Excel 导入、状态流转、排查备注、**自定义台账**（`b04_saved_view`，保存筛选条件 → 引用原任务 → 视图内改状态回写原台账）。

但存在一个已规划未实现的能力缺口（上位需求 §1.2 / §8.1 D6 明确「标签管理二期」；`b04_saved_view.filter_config` 已「预留标签维度」）：

- 用户无法对**单个任务打标签**，也无法**按标签筛选**任务；
- 平台缺少**标签管理**能力（标签 ID / 名称 / 描述 / 分类 / 颜色）；
- 自定义台账当前仅「动态引用视图」，不能满足「把筛选命中的任务**固化**成一个固定工作清单台账」的诉求。

本需求整体补全上述能力，并在 V1.1 中按本次优化反馈做了以下调整：

1. **标签管理独立成模块**：作为空间内独立一级菜单（概念对应 `CODEBUDDY.md` §3.2 预留的 `b06_`），UI/路由独立，但数据仍空间级（存空间库 `b04_tag`，延续 V1.0 D2 空间隔离）；
2. **标签分类**：标签新增「管理标签 / 技术标签」分类，新增默认「技术标签」，用于标签选择器内分组；
3. **内联 + 号打标**：任务清单表格「标签」列末尾提供 `+` 图标，点击弹出**已创建标签**多选浮层（按分类分组），选中即就地打标；浮层内不可新建标签，去掉标签点击标签 `×` 即可；
4. **缺陷修复**：修复「含全部标签（AND）」筛选无结果的后端查询逻辑；新增/编辑/删除标签后标签列表与任务表格「标签」列实时刷新，无需手动刷新页面。

### 1.2 范围
| 模块 | 归属 | 本期范围 |
| --- | --- | --- |
| 标签管理（独立模块） | `b04`（空间内，UI 独立成 `b06` 概念菜单） | 空间级标签 CRUD（ID/名称/描述/分类/颜色），多对多关联任务 |
| 任务打标签 | `b04` | 单任务打标、列表批量打/去标签、**列表内联 + 号打标（仅已有标签）** |
| 按标签筛选 | `b04` | 任务台账列表按标签筛选（含全部=AND / 任一=OR，组合其他条件） |
| 自定义台账升级 | `b04` | 自定义台账新增「动态 / 固化」模式，固化模式锁定命中 ID |
| 标签化台账视图 | `b04` | 台账视图内展示标签、状态变更回写原任务 |
| 缺陷修复 | `b04` | AND 筛选无结果修复；标签增删改后实时刷新 |

**不在本期范围**：

- 标签**全局/跨空间共享**：本期标签严格空间级（`mig_<space_code>_db`），不做公共库 `mig_common_db` 标签（V1.1 D9 已确认不打破 D2 空间隔离）；
- 标签作用于 `b03` 数据迁移或 `b05` 校验：本期仅 `b04` 任务（上位需求 §8.1 D6 二期占位解除，但范围仍限于 b04）；
- 标签驱动的自动归组/统计看板：本期仅作为筛选与台账维度，看板类（b99）二期；
- 腾讯文档导入的「标签列」：本期在线文档导入不处理标签维度（延续在线文档需求 §1.2）；
- 标签浮层内新建标签：内联打标仅可选已有标签，新建标签统一在「标签管理」模块完成。

### 1.3 术语
| 术语 | 含义 |
| --- | --- |
| 标签 | 空间内对任务的一种分类标记，含 标签ID / 名称 / 描述 / 分类 / 颜色，由 `b04_tag` 维护 |
| 标签分类 | `manage`（管理标签）/ `tech`（技术标签，默认）；用于标签选择器内分组展示，两类均可赋予任务 |
| 任务打标签 | 在 `b04_task` 与 `b04_tag` 间建立多对多关联（经 `b04_task_tag`） |
| 内联打标 | 任务清单表格「标签」列 `+` 图标弹出的已创建标签多选浮层，选中即就地打标（不可新建） |
| 按标签筛选 | 任务台账列表筛选栏多选标签，按匹配规则（全部=AND / 任一=OR）过滤任务 |
| 自定义台账 | 既有能力：保存筛选条件形成视图（`b04_saved_view`），数据引用原任务（非副本） |
| 动态台账 | 自定义台账的原有模式：运行时按 `filter_config` 实时计算命中任务，任务改标签会自动移出/加入 |
| 固化台账 | 本需求新增模式：保存时把当前筛选命中的任务 ID 集合锁定为台账成员，后续成员固定（即使任务改标签/状态也不移出），任务状态变更仍回写原任务 |

## 2. 总体设计

```
空间内导航（独立菜单，b06 概念）
  ├─ 标签管理（独立模块，b04_tag 空间库）
  │    ├─ 标签 CRUD（ID / 名称 / 描述 / 分类[manage|tech] / 颜色）
  │    └─ 多对多关联 b04_task（经 b04_task_tag）
  └─ 任务迁移管理（b04）
       ├─ 任务台账（b04_task）  ← 列表「标签」列 + 内联 + 号打标 + 按标签筛选 + 批量打标
       │    └─ 单任务打标 / 去标（详情 / 行内 / 批量 / 内联+）
       └─ 自定义台账（b04_saved_view，升级）
            ├─ view_mode = dynamic（沿用现状：filter_config 实时计算）
            └─ view_mode = fixed（固化：保存时快照命中 task_id → b04_saved_view_member）
                 └─ 台账视图：展示成员任务 + 标签；状态变更回写 b04_task（单一真实来源）
```

- **标签归属与模块落位**：标签存空间库 `mig_<space_code>_db`，仅本空间可见/可用，符合平台空间隔离原则（D2）；V1.1 起「标签管理」以**独立一级菜单**呈现（概念对应 `CODEBUDDY.md` §3.2 预留 `b06_`），但**不**新建 `b06` 表/库，后端 API 仍归入 `b04` 服务操作 `b04_tag`，避免与空间隔离冲突（D9）；
- **任务-标签关系**：多对多，经 `b04_task_tag` 关联；`b04_task` 本身**不加标签字段**（与上位需求 §6.5.2 注释一致，二期仅新增 `b04_tag` / `b04_task_tag`）；
- **单一真实来源**：无论动态还是固化台账，视图展示的任务数据均来自 `b04_task`；台账内状态更新直接 UPDATE 原任务行，台账不存副本；
- **固化 vs 动态**：固化台账保存时把筛选命中的 `task_id` 写入 `b04_saved_view_member`，查询与展示以成员表为准；动态台账不写成员，运行时按 `filter_config`（含 `tag_ids` 维度）计算；
- **实时刷新**：标签的增/删/改操作后，前端对标签列表与任务表格「标签」列做响应式刷新（重拉或状态更新），无需手动刷新页面（A12）。

## 3. 功能要点

### 3.1 标签管理（独立模块，空间级）
- **入口**：空间内**独立一级菜单「标签管理」**（与任务迁移管理并列，概念对应 `CODEBUDDY.md` §3.2 预留 `b06_`）；L0/L1/L2 均可维护（上位需求 §2.2 业务操作权限）；
- **标签字段**：
  - 标签 ID（系统生成，展示用）
  - 标签名称（空间内唯一）
  - 标签描述（选填）
  - 标签分类（`manage` 管理标签 / `tech` 技术标签，**新增默认 `tech`**）
  - 颜色（hex，从预设调色板选取，默认主色 `#1a73e8`）
- **操作**：新增 / 编辑 / 删除（删除需二次确认）；
- **删除标签**：解除 `b04_task_tag` 中该标签的全部关联（级联删除关联行），**不影响任务本身**；
- **列表**：展示全部标签（名称 / 描述 / 分类 / 色块 / 已关联任务数），可搜索；新增/编辑/删除后列表实时刷新（A12）。

### 3.2 任务打标签
- **单任务**：任务详情或列表行内「打标签」入口，弹窗多选标签赋值；支持去标；
- **内联 + 号打标（V1.1 新增）**：任务清单表格「标签」列末尾显示 `+` 图标，点击弹出**已创建标签**多选浮层（按「管理标签 / 技术标签」分组展示），选中即**就地**为该任务打标；浮层内**不可新建**标签（新建统一在标签管理模块完成）；点击任务已有标签上的 `×` 可**就地**去标；
- **批量打标签**：列表多选任务 → 「批量打标签」弹窗（多选标签），对选中任务批量赋予；提供「批量去标签」移除选中任务上的指定标签；
- 关联写入 `b04_task_tag`（唯一约束 `(task_id, tag_id)`），重复打同一标签幂等。

### 3.3 按标签筛选任务
- 任务台账列表筛选栏新增「标签」多选控件；
- **匹配规则**（V1.1 明确语义）：
  - **含全部所选标签（AND）**：任务须**同时拥有**所有选中标签；
  - **含任一所选标签（OR）**：任务拥有任一选中标签即命中；
  - 前端提供「全部 / 任一」切换，**默认「全部（AND）」**；
- **缺陷修复（F1）**：当前「含全部标签（AND）」筛选搜不到数据为**后端查询缺陷**——多标签 AND 需正确实现（如对 `tag_ids` 做 `IN` + 按 `task_id` 聚合 `HAVING COUNT(DISTINCT tag_id) = N`），须修复使 AND 生效；修复后须验证 0/1/多标签及与其他筛选条件组合的命中正确性；
- 支持与其他筛选条件（工作流 / 迁移状态 / 调度状态 / 校验状态 / Owner / 任务名称）**组合**；
- 筛选结果可导出、可「保存为台账」（见 §3.4）。

### 3.4 自定义台账升级（动态 + 固化）
在既有「保存为台账」流程上增加 **视图模式** 选择：

1. **动态台账（沿用）**：保存筛选条件（`filter_config`，本期开启其中的 `tag_ids` 维度），运行时实时计算命中任务；
2. **固化台账（新增）**：保存时对当前筛选命中结果做 ID 快照，写入 `b04_saved_view_member`（锁定成员）；后续即使任务改标签、改状态，仍保留在台账中；
3. 保存时填写台账名称、描述、模式；
4. 台账列表在场景下展示，点击进入台账视图；
5. **视图内操作**：展示成员任务（含标签列），支持状态更新，结果**回写原 `b04_task`**（与上位需求 §6.4.4 一致）；
6. **编辑台账**：可改名称 / 描述 / 筛选条件 / 模式；
   - 动态 → 固化：切换时按当前 `filter_config` 重新快照并写入成员表；
   - 固化 → 动态：清空成员表，改为运行时计算；
7. **删除台账**：仅删 `b04_saved_view` 与成员记录（`b04_saved_view_member`），**不删任务**；
8. 固化台账成员中若原任务被逻辑删除（`b04_task.deleted_at` 非空），台账仍展示该成员并标记「源已删除」，状态不可再变更。

### 3.5 标签化台账视图
- 台账视图（动态/固化）均展示「标签」列（色块 + 文字胶囊，圆角 `10px`、字号 `11px`，见 `CODEBUDDY.md` §6.4.2 标签样式）；
- 状态变更、批量操作同既有自定义台账，回写 `b04_task`；
- 固化台账视图顶部标注「固化台账 · 成员 N」，提示成员已锁定。

### 3.6 本次优化缺陷修复项（V1.1 新增）
| 编号 | 缺陷/优化 | 说明与验收 |
| --- | --- | --- |
| F1 | 「含全部标签(AND)」筛选无结果 | 后端多标签 AND 查询逻辑缺陷；修复后任务须同时命中所有所选标签；验证 0/1/多标签及与工作流/状态等条件组合；同时保留「含任一(OR)」选项 |
| F2 | 新增标签后需手动刷新才可见 | 标签新增/编辑/删除后，标签列表与任务表格「标签」列实时刷新（前端响应式重拉或状态更新），无需手动刷新页面 |

## 4. 数据模型（空间库 `mig_<space_code>_db`）

### 4.1 标签主表（`b04_tag`，新增）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | BIGINT | PK，自增 | 标签 ID（主键，亦作展示用标签 ID） |
| `space_id` | BIGINT | 非空 | 所属空间 |
| `tag_name` | VARCHAR(64) | 非空，空间内唯一 | 标签名称 |
| `tag_description` | VARCHAR(512) | 可空 | 标签描述 |
| `tag_category` | VARCHAR(16) | 非空，默认 `tech` | 标签分类：`manage`（管理标签）/ `tech`（技术标签，默认） |
| `color` | VARCHAR(16) | 非空，默认 `#1a73e8` | 标签颜色（hex，预设调色板选取） |
| 审计字段 | — | 必填 | `created_by` / `created_at` / `updated_by` / `updated_at` / `deleted_at` |

> 唯一约束：`(space_id, tag_name)`（未删除）。`tag_category` 取值枚举：`manage` / `tech`，新增默认 `tech`（A11）。

### 4.2 任务-标签关联表（`b04_task_tag`，新增）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | BIGINT | PK，自增 | 主键 |
| `space_id` | BIGINT | 非空 | 所属空间 |
| `task_id` | BIGINT | 非空 | 关联 `b04_task.id` |
| `tag_id` | BIGINT | 非空 | 关联 `b04_tag.id` |
| 审计字段 | — | 必填 | `created_by` / `created_at` / `updated_by` / `updated_at` |

> 唯一约束：`(task_id, tag_id)`，避免重复关联；删除标签时级联删除关联行。

### 4.3 任务台账表（`b04_task`，**不新增标签字段**）
沿用上位需求 §6.5.2 全部字段，**不加**标签列（标签经 `b04_task_tag` 多对多关联，与上位需求 §6.5.2 注释一致）。

### 4.4 自定义台账表（`b04_saved_view`，增量字段）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `view_mode` | VARCHAR(16) | 非空，默认 `dynamic` | `dynamic`（动态引用）/ `fixed`（固化，锁定成员） |

> 其余字段（`space_id` / `scenario_id` / `name` / `description` / `filter_config` / 审计字段）沿用上位需求 §6.5.4；`filter_config` 新增 `tag_ids`（数组）与 `tag_match`（`all` / `any`）维度，开启上位需求 §6.4.6 预留的标签维度。

### 4.5 固化台账成员表（`b04_saved_view_member`，新增，仅固化模式使用）
| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | BIGINT | PK，自增 | 主键 |
| `space_id` | BIGINT | 非空 | 所属空间 |
| `view_id` | BIGINT | 非空 | 关联 `b04_saved_view.id` |
| `task_id` | BIGINT | 非空 | 关联 `b04_task.id`（快照成员） |
| 审计字段 | — | 必填 | `created_by` / `created_at` / `updated_by` / `updated_at` |

> 唯一约束：`(view_id, task_id)`；动态模式台账不写入此表。

## 5. 接口与交互概要

均置于 `/api/v1/b04` 路由分组（标签管理虽为独立 UI 模块，但数据在空间库 `b04_tag`，后端 API 仍归入 `b04` 服务，见 D9），统一响应 `{ code, message, data, trace_id }`：

- **标签管理（独立模块）**：`GET/POST /tags`、`GET/PATCH/DELETE /tags/{id}`（空间内 CRUD，含 `tag_category` 字段）；列表返回 名称/描述/分类/颜色/已关联任务数；
- **任务标签**：`GET /tasks/{id}/tags`、`PUT /tasks/{id}/tags`（整体替换该任务标签，幂等）；`POST /tasks/batch-tags`（批量赋予）、`DELETE /tasks/batch-tags`（批量移除），请求体含 `task_ids[]` 与 `tag_ids[]`；**内联 + 号打标复用上述接口**（仅传已有 `tag_id`，不可新建）；
- **按标签筛选**：`GET /scenarios/{id}/tasks` 新增 `tag_ids`（逗号分隔）、`tag_match`（`all`/`any`）查询参数；`tag_match=all` 须正确实现 AND 命中（修复 F1），与既有筛选参数组合；
- **任务列表响应**：补充 `tags[]`（含 id/name/category/color）供列表「标签」列渲染与内联 `+` 浮层分组展示；
- **标签实时刷新**：标签增删改接口成功后，前端刷新标签缓存 → 标签列表页与任务表格「标签」列实时更新（F2）；
- **自定义台账**：`POST /scenarios/{id}/saved-views`（请求体含 `view_mode`）、`GET`、`PATCH`（可改 `view_mode`，切换时由后端重建/清空成员）、`DELETE`；固化模式保存时后端写入 `b04_saved_view_member`；
- **台账视图任务**：沿用既有任务列表/状态更新接口（按 `view_mode` 决定取数来源：固定成员 or 实时筛选）；状态更新接口复用既有任务状态流转（回写 `b04_task`）。

## 6. 安全与质量约束

1. **空间隔离**：标签、`b04_task_tag`、固化成员均带 `space_id`，查询与写入强制按当前空间过滤，禁止跨空间访问；
2. **权限**：标签管理与打标属空间内业务操作，L0/L1/L2 均可（上位需求 §2.2）；越权由后端 `Depends` 统一拦截；
3. **删除安全**：删除标签级联解除关联但不删任务；删除台账仅删视图与成员，不删任务；
4. **单一真实来源**：台账视图内状态变更直接 UPDATE `b04_task`，台账不存任务副本，避免数据分裂；
5. **审计**：标签增删改、任务打/去标、台账保存/编辑/删除均记录操作人与时间（审计字段）；
6. **分层与响应**：router → service → repository → model 分层，跨层 Pydantic Schema 传递（`CODEBUDDY.md` §5）；
7. **视觉一致**：标签胶囊严格采用 `CODEBUDDY.md` §6.4.2 样式（圆角 `10px`、字号 `11px`、色块 + 文字），不引入第二套配色；内联 `+` 图标与去标 `×` 交互遵循同套视觉语言；
8. **实时刷新**：标签变更后前端须保证标签列表与任务表格标签列实时同步，避免「需手动刷新」（F2）。
