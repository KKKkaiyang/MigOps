# 迁移管家（MigOps）任务迁移 — 任务台账需求

> 文档版本：V1.0 ｜ 编写日期：2026-10-23 ｜ 状态：需求确认版（关键决策见 §8，已交互确认）
> 适用范围：任务迁移管理（`b04`）的「自定义台账」（`b04_saved_view`，saved-views）能力升级——**独立台账清单入口**、**台账内搜索与操作对齐任务列表**、**勾选任务创建固化台账**、**移除任务转固化**。
> 配套文档：`docs/业务需求/任务迁移-标签管理与标签化台账需求.md`（标签体系与按标签筛选，本需求复用其标签筛选能力）、`docs/业务需求/项目空间业务功能需求.md`（上位 `b04` 需求）、`docs/业务需求/迁移管家平台-业务需求文档.html`（平台总 BRD）。

## 1. 概述

### 1.1 背景与目标
任务迁移「自定义台账」当前已具备：从任务列表「保存为台账」生成视图（`b04_saved_view`，存 `filter_config` + `view_mode`），数据**引用原任务**（非副本），视图内改状态回写原台账；并已在「标签化台账」需求中补齐 `dynamic`（动态引用）/ `fixed`（固化，锁定命中 ID）两种模式。

但现有体验存在四处缺口（即本期 4 项需求）：

- **无独立台账清单入口**：台账仅在场景栏 `ScenarioBar` 以链接内联展示，没有可集中查看/管理「全部台账」的列表页；
- **台账详情页能力弱**：`SavedViewList` 仅展示筛选标签 + 状态流转 + 导出，缺少与任务列表一致的**搜索栏**与**完整操作按钮**（详情/备注、移除、批量等）；
- **创建方式单一**：只能"按筛选保存"，无法"勾选若干具体任务"直接落成固化台账；
- **无法从台账移除任务**：`update_saved_view` 仅在改 `filter_config`/`view_mode` 时整体重建成员，没有"移出某几条并锁定剩余"的入口，也无"移除即转固化"语义。

本需求整体补全上述能力，使台账成为可独立查看、可搜索、可操作的"工作清单"载体。

### 1.2 范围
| 能力 | 归属 | 本期范围 |
| --- | --- | --- |
| 台账清单入口 | `b04` | 任务迁移模块内独立「任务台账」列表页（按当前场景汇总） |
| 台账内搜索 | `b04` | 复用任务列表筛选栏；动态=基础∩搜索，固化=成员内过滤 |
| 台账内操作 | `b04` | 状态流转 / 详情备注 / 移除任务 / 批量操作（批量状态流转 + 批量打标签） |
| 勾选任务建台账 | `b04` | 任务列表勾选 → 生成 `fixed` 台账（成员=勾选 ID） |
| 筛选保存建台账 | `b04` | 沿用「保存为台账」，默认 `dynamic`（两种方式并存） |
| 移除转固化 | `b04` | 从任意类型台账移除任务 → 置 `fixed` 并锁定剩余成员 |

**不在本期范围**：

- 跨场景 / 跨空间台账汇总：入口按当前场景，不做全局聚合；
- 台账成员的批量导入 / 独立导出成员清单；
- 台账与原任务的字段级差异对比视图；
- 动态台账转固化之外的其它模式（如定时快照、版本历史）。

### 1.3 术语
| 术语 | 含义 |
| --- | --- |
| 自定义台账 / 任务台账 | `b04_saved_view` 保存的视图，数据引用原任务（非副本） |
| 动态引用（dynamic） | 运行时按 `filter_config` 实时计算命中任务，原任务改标签/状态会移出或加入 |
| 固化台账（fixed） | 保存时（或移除任务后）将任务 ID 集合锁定进 `B04SavedViewMember`，成员固定，状态变更仍回写原任务 |
| 台账成员 | 固化台账锁定的任务集合（`B04SavedViewMember`），决定台账展示的任务 |
| 搜索叠加 | 台账详情页内的筛选条件与台账基础（动态筛选 / 固化成员）的组合方式 |
| 从台账移除 | 解除某任务与台账的成员关系（**不删除原任务**），并触发转固化 |

## 2. 需求清单（本期 4 项）

- **R1 独立台账清单入口**：任务迁移管理内提供单独的入口，可查看台账列表（名称/描述/模式/任务数等），并能进入具体台账。
- **R2 台账内搜索 + 操作对齐**：进入具体台账后，可使用与任务迁移列表一致的搜索功能；并提供任务列表同款操作按钮。
- **R3 勾选创建固化台账**：从任务列表勾选具体任务创建台账时，视图模式固定为「固化台账」；与"按筛选保存"并存。
- **R4 移除转固化**：从台账中移除一条或多条任务后，该台账无论原为何种类型，都改为「固化台账」并锁定剩余成员。

## 3. 功能设计

### 3.1 R1 — 独立台账清单入口
- **位置**：在任务迁移管理模块内新增「任务台账」列表页（按当前所处 `scenario_id` 列出该场景全部台账）。场景栏 `ScenarioBar` 现有内联链接可保留为快捷入口，但权威的台账列表统一收敛到该页。
- **页面内容**（表格列）：
  - 台账名称、描述；
  - 模式标签（`动态引用` / `固化台账`）；
  - 任务数（`task_count`，动态按 `filter_config` 计、固化按成员表计）；
  - 创建人、创建时间；
  - 操作：`打开`（进入详情页）、`编辑`（名称/描述/模式）、`删除`。
- **跳转**：点击行或「打开」→ 进入 §3.2 台账详情页（`space-saved-view`）。

### 3.2 R2 — 台账详情页：搜索 + 操作对齐
- **搜索栏**：复用任务列表的 `TaskFilterBar`（关键词 / 工作流 / Owner / 迁移状态 / 调度状态 / 校验状态 / 标签含全部=AND、任一=OR）。
- **搜索叠加（已确认 D4）**：
  - **动态台账**：最终结果 = `filter_config` 基础筛选 **∩** 搜索条件，运行时实时计算；
  - **固化台账**：在锁定的 `B04SavedViewMember` 成员**内**按搜索条件过滤，**不增删成员**。
- **表格列对齐任务列表**：任务 / 工作流 / Owner / 迁移状态 / 调度状态 / 校验状态 / 标签 / 操作（列定义与任务迁移列表保持一致；最新备注按任务列表同决策不展示，保持视觉与行为一致）。
- **行多选**（`type="selection"`）支持，供「移除任务」「批量操作」使用。
- **操作按钮（已确认 D2，全部提供）**：
  1. **状态流转**：行内修改迁移/调度/校验状态，回写原任务；
  2. **详情 / 备注**：打开任务详情抽屉（排查备注时间线、编辑）；
  3. **移除任务**：勾选后「从台账移除」→ 触发 R4 固化转换；
  4. **批量操作**：批量状态流转 + 批量打标签；
  5. 另保留现有**导出**能力。
- **关键边界**：「从台账移除」仅解除成员关系，**不删除原任务**（区别于任务列表的删除任务）。

### 3.3 R3 — 创建台账：两种方式并存（已确认 D3）
- **方式 A（沿用）**：任务列表「保存为台账」→ 弹窗填名称/描述/模式，默认 `dynamic`（动态引用）。
- **方式 B（新增）**：任务列表勾选若干任务 → 顶部「创建台账」按钮 → 弹窗（仅名称/描述）→ 提交后生成 `view_mode=fixed` 的台账，**成员 = 勾选的任务 ID 集合**（直接锁定，不依赖筛选快照）。
- **后端约定**：`create_saved_view` 支持可选 `member_ids`；当 `view_mode=fixed` 且传入 `member_ids` 时，直接写入 `B04SavedViewMember`，`filter_config` 可留空。

### 3.4 R4 — 移除任务 → 转固化（已确认 D4 语义外延）
- **入口**：台账详情页勾选任务（单条或批量）→「从台账移除」。
- **行为**（无论原 `view_mode` 为何）：
  1. 计算**剩余成员** = 当前成员 − 被移除项；
  2. `view_mode` 置为 `fixed`（固化）；
  3. 将剩余成员持久化为 `B04SavedViewMember` 锁定集合，后续成员固定；
  4. `filter_config` 不再驱动成员（可保留但被成员表覆盖，或清空）。
- **动态台账的特殊处理**：动态台账本无成员表，"移除"即完成"固化快照"——以 **当前命中集 − 被移除项** 为初始锁定成员，再置 `fixed`。
- **不可逆**：转固化后不再回退为动态（除非删除重建）。
- **空台账**：若移除全部，则 `fixed` 成员为空，列表/搜索为空。
- **后端约定**：新增接口（如 `POST /b04/saved-views/{id}/remove-members`，体 `{task_ids:[...]}`），内部执行上述转换与成员持久化。

## 4. 后端变更要点
- `create_saved_view`：支持 `member_ids` 直接建立固定成员（`fixed` 且传入时写成员表，`filter_config` 可空）。
- 新增 `remove_members(view_id, task_ids)`：转 `fixed` + 锁定剩余成员（动态先快照再减）。
- `list_saved_view_tasks`：新增搜索参数透传（keyword / workflow_name / 各状态 / owner / tag_ids / tag_match），按 D4 规则叠加（动态 ∩ / 固化内过滤）。
- `get_saved_view_out`：任务数统计在 `fixed` 下基于成员表（已具备），无需改动。
- 复用既有逻辑：`_snapshot_members` / `_rebuild_members` 可作为固化落地的内部实现。

## 5. 前端变更要点
- 新增**任务台账列表页**（按场景），复用 `listSavedViews`。
- 重构 `SavedViewList`：增加 `TaskFilterBar`、行多选、操作按钮组（状态流转/详情/移除/批量）、导出；移除现有无意义的"去台账"按钮。
- `TaskMigrationList`：增加基于 `selection` 的「创建台账」入口（方式 B）。
- 复用既有组件：`TaskFilterBar`、`TaskStatusCell`、`TaskDetailDrawer`、`BatchTagDialog`、批量状态流转，保证与任务列表体验一致。

## 6. 验收标准
- **AC1（入口）**：任务迁移模块内有「任务台账」页，列出当前场景全部台账及模式/任务数，可进入详情。
- **AC2（搜索）**：台账详情页可用与任务列表一致的筛选栏；动态台账验证"基础∩搜索"、固化台账验证"成员内过滤"。
- **AC3（操作）**：状态流转 / 详情备注 / 移除任务 / 批量操作均在台账页可用，状态变更回写原任务。
- **AC4（创建）**：勾选任务创建 → 生成 `fixed` 台账且成员锁定；「保存为台账」→ `dynamic`；两种方式并存。
- **AC5（移除转固化）**：从任意类型台账移除任务 → 该台账变 `fixed`、剩余成员锁定、原任务不被删除；动态台账移除后变为固化锁定集。

## 7. 关联与边界
- 标签筛选能力（含全部=AND / 任一=OR）由「标签化台账」需求提供，本需求在台账搜索栏中复用，不重复定义。
- 本需求文档聚焦"台账的查看/搜索/操作/创建/移除"，与「标签管理」模块职责分离。

## 9. 补充需求：固化台账补充新增任务（2026-10-23）

### 9.1 需求描述
用户在实际使用中发现：固化台账（fixed）一旦创建，成员即被锁定，无法再往里加任务。补充需求为——**固化台账可以再补充新增任务**；新增方式复用迁移管理页的搜索能力，即"**回到迁移管理页面，搜索并勾选任务后再加入台账**"。

### 9.2 决策（已确认）
| 编号 | 决策点 | 结论 |
| --- | --- | --- |
| D5 | 目标台账范围 | 任意台账均可作为补充目标；若选中的是动态引用台账，加入时**自动固化为成员集合**（与 D4 移除即转固化保持一致语义） |
| D6 | 完成后的返回行为 | 从某台账内「补充任务」跳转而来时，加入成功后**自动返回原台账**详情页 |

### 9.3 交互流程
1. 台账详情页（`SavedViewList`）新增「补充任务」按钮 → 跳转迁移管理页（`space-tasks`），并携带上下文 `?addToView=<viewId>&scenarioId=<scenarioId>`；任务页顶部出现上下文横幅提示"正在为【台账名】补充任务"。
2. 迁移管理页复用 `TaskFilterBar` 搜索 + `el-table` 多选，选中后点击「添加到台账（N）」打开 `AddToLedgerDialog`。
3. 对话框列出当前场景全部台账（标注 固化/动态 与任务数）；若带 `addToView` 上下文则预选并锁定该台账。确认 → 调用 `addSavedViewMembers`。
4. 成功后：带上下文则自动返回该台账详情；否则停留任务页并提示成功、清空选择。

### 9.4 后端变更
- 新增 schema `SavedViewAddMembers`（`task_ids: List[int]`，`min_length=1`）。
- `services.b04_task_migration.add_members`：动态台账先 `_snapshot_members` 转固定，再用既有 `_set_members_from_ids` 加入任务（幂等：已有/逻辑删除成员复活）。
- 新增路由 `POST /b04/saved-views/{view_id}/add-members`。

### 9.5 前端变更
- `api/task-migration.ts`：新增 `addSavedViewMembers(spaceId, viewId, taskIds)`。
- 新增组件 `components/AddToLedgerDialog.vue`：列出场景台账并落选目标。
- `TaskMigrationList.vue`：新增「添加到台账（N）」按钮、上下文横幅、读取 `addToView`/`scenarioId` 查询参数、成功后按上下文返回。
- `SavedViewList.vue`：新增「补充任务」按钮跳转并带上下文。

### 9.6 验收标准
- **AC6（补充入口）**：任一台账详情页可「补充任务」跳回迁移管理页并带上下文横幅。
- **AC7（加入固化台账）**：在任务页搜索勾选 → 加入 → 该台账成员增加，任务数更新；幂等（重复加入不产生重复成员）。
- **AC8（动态自动固化）**：向动态引用台账补充任务 → 台账转为 `fixed`（成员=原命中集+新加入任务）。
- **AC9（自动返回）**：从台账内发起的补充任务，加入成功后自动回到该台账详情页。
