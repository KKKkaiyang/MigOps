P5任务台账：清单 + 详情 + 内嵌「补充任务」抽屉

对应评审问题 I4 补充任务跳转链路 / I5 概念复杂 / I6 路由层级。路由统一为 /space/:id/tasks/ledgers 与 /space/:id/tasks/ledgers/:viewId。

Before：补充任务整页跳转（5 步）

  1. 台账详情页点「补充任务」
  2. 整页跳转任务列表（query 带上下文）
  3. 搜索 + 勾选任务
  4. 「添加到台账」弹窗确认
  5. 依赖路由逻辑返回原台账

After：抽屉内嵌完成（3 步，不离开页面）

  1. 台账详情页点「补充任务」→ 右侧抽屉打开
  2. 抽屉内搜索勾选（默认仅展示当前场景未入账任务）
  3. 确认 → 原地刷新台账，动态台账弹出「转为固定名单」显式告知
