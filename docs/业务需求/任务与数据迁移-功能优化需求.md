# 迁移管家（MigOps）任务迁移与数据迁移 — 功能优化需求

> 文档版本：V1.0 ｜ 编写日期：2026-10-23 ｜ 状态：需求确认版（已交互确认关键决策 D1~D4）
> 适用范围：任务迁移管理（`b04`）与数据迁移管理（`b03`）四项功能优化——① `b04_task` 新增「数仓项目空间」字段；② 任务列表「导入任务台账」按钮改名为「导入基础数据」；③ 任务详情「输入输出表」清单改由血缘（`b07`）实时关联取得并忽略临时表；④ 任务详情与数据迁移的表名点击，以**对话框**形式弹出血缘**受限视图**（固定根表、无检索栏、可上下钻取、节点右键查看详情）。

## 1. 概述

### 1.1 背景与目标
任务迁移与数据迁移模块在实际使用中存在四处体验/语义问题，本期做针对性优化：

1. **数仓空间归属缺失**：任务迁移数据模型缺少「源端数据中台数仓空间」维度，无法标识任务所属的数仓业务空间（如腾讯 wedata 按业务模块拆分的数仓）。
2. **导入按钮语义误导**：任务迁移列表的「导入任务台账」按钮，实际功能是 Excel/CSV 导入**任务基础数据**，名称易让人误以为是「台账」相关导入。
3. **输入输出表来源不准**：任务详情页的输入/输出表清单当前取自导入时填写的 `input_tables`/`output_tables` 字段，未与血缘打通，且混入临时表。
4. **表名不可追溯血缘**：任务详情与数据迁移列表中的表名仅作文本展示，点击无法直达血缘；现有 b07 血缘是独立页（带检索栏），缺乏「就地查看当前表血缘」的轻量入口。

本期在**不破坏既有能力**（自定义台账、血缘独立页）的前提下补齐上述四点。

### 1.2 范围
| 能力 | 归属 | 本期范围 |
| --- | --- | --- |
| 数仓项目空间字段 | `b04` | `b04_task` 新增 `dw_project_space` 字段；导入模板与列表/详情展示同步 |
| 导入按钮改名 | `b04` | 任务列表「导入任务台账」→「导入基础数据」（功能不变） |
| 输入输出表关联血缘 | `b04` | 任务详情「输入输出表」清单改由 `b07` 血缘按 `task_uri` 关联取得，过滤临时表 |
| 血缘受限弹层 | `b04` + `b03` | 表名点击 → 对话框内嵌 `b07` LineageGraph（隐藏检索栏、固定根表、可钻取、右键详情） |

**不在本期范围**：
- 修改 b07 血缘独立页（space-lineage）的既有检索能力（本期仅新增其受限嵌入形态）；
- 台账能力、标签体系、在线文档导入（已作废）的改动；
- 数仓项目空间字段与 b01 迁移空间的任何关联逻辑（二者为不同概念，仅命名区分）。

### 1.3 术语
| 术语 | 含义 |
| --- | --- |
| 数仓项目空间 | **源端**数据中台（如腾讯 wedata）按业务模块拆分的数仓空间；本需求新增字段 `dw_project_space` 标识，**与 MigOps「项目空间（= 迁移空间/隔离单元 `b01_space`）」是完全不同的概念**，仅中文简称相近，须严格区分 |
| 受限血缘视图 | 内嵌于对话框的血缘可视化：根表固定为被点击的表、隐藏检索栏、仅允许节点 `+/−` 与右键菜单上下钻取 |
| 临时表（沿用 b07） | 血缘中表类型之一，本需求**仅**在「任务详情输入输出表清单」中过滤掉临时表；血缘图本身仍按 b07 D6 始终渲染临时表 |

## 3. B04-01 任务迁移新增「数仓项目空间」字段

### 3.1 功能描述
在任务迁移数据模型（`b04_task`）新增字段，标识该任务所属**源端数据中台数仓空间**（如 wedata 业务模块空间），用于按数仓空间维度归并与检索任务。

### 3.2 数据模型变更（空间库）
- 表：`b04_task`（沿用上位需求 §6.5.2，唯一约束 `(scenario_id, task_uri)` 不变）。
- 新增列：`dw_project_space` `VARCHAR(255)` 可空，显示名「数仓项目空间」。
- 不新增索引（按场景+字段筛选即可，如需频繁按该字段筛选可后续加 `idx_b04_dw_space`）。

### 3.3 导入与展示
- **导入模板**：Excel/CSV 导入（上位需求 §6.4.2）增加「数仓项目空间」列，导入时映射到 `dw_project_space`；覆盖/增量两种模式均支持该列更新。
- **列表/详情**：任务列表可增加该列（列显隐复用既有机制）；任务详情页展示该字段。
- **筛选（建议）**：任务列表筛选栏可增加「数仓项目空间」条件（沿用既有属性筛选组合模式），本期可选实现。

### 3.4 边界与区分
- **严禁与迁移空间混淆**：文档与界面均使用「数仓项目空间」全称，`dw_project_space` 列名带 `dw_` 前缀；不可简写为「项目空间」以免与 b01 迁移空间（`b01_space` / 项目空间管理）混淆（见 §1.3、决策 D1）。
- 该字段为源端描述性属性，不参与空间隔离、权限、血缘关联等逻辑。

## 4. B04-02 导入按钮改名「导入基础数据」

### 4.1 功能描述
任务迁移列表的导入入口按钮文案由「导入任务台账」调整为「导入基础数据」，消除「导入的是台账」这一语义误导；**导入行为本身不变**。

### 4.2 改动点（仅文案，功能不变）
- 按钮文案：`导入任务台账` → `导入基础数据`。
- 功能沿用：Excel/CSV 导入（覆盖导入 / 增量导入两种模式）、模板下载、行级错误提示（上位需求 §6.4.2 / 总文档 §5.3.1）。
- 同步更新：原型 `迁移管家平台-界面原型.html` 中任务列表「导入台账」按钮（见原型任务列表区）一并改为「导入基础数据」；模板文件名/下载文案保持一致。
- 总文档 §5.3.1「导入」描述可保留功能说明，按钮名称以本需求为准。

### 4.3 不改动项
自定义台账（§5.3.3/§5.3.4）、标签化台账、在线文档导入（已作废）等均与本次改名无关。

## 5. B04-03 任务详情输入输出表改由血缘关联、忽略临时表

### 5.1 功能描述
任务详情页的「输入表 / 输出表」清单，数据源由 b04_task 导入时填写的 `input_tables`/`output_tables` 字段，**改为按本任务的 `task_uri` 实时关联 `b07` 血缘**取得，且清单中**忽略临时表**（仅展示正式表）。

### 5.2 关联逻辑（已确认 D3）
- 解析 `b04_task.task_uri`（格式 `项目名称://任务名称@工作流名称`）得到 `(任务名称, 工作流名称)` 二元组；
- 在 `b07_lineage` 中匹配 `task_name = 任务名称 AND workflow_name = 工作流名称` 的全部边；
- 汇总这些边的 `input_table`（去重，作为输入表清单）与 `output_table`（去重，作为输出表清单）；
- **过滤临时表**：依据 `input_table_type` / `output_table_type`，丢弃类型为「临时表」的条目，**仅保留正式表**展示（b07 D6 仅约束血缘图渲染，不影响本清单过滤）。

### 5.3 展示与交互
- 任务详情页输入表区、输出表区分别渲染上述正式表清单；
- 每个表名**可点击**，点击触发 B04-04 血缘对话框（以该表为根表）；
- 若 `b07` 中该任务无血缘记录，清单为空并提示「该任务暂无血缘关系」。

### 5.4 后端接口
- 复用/扩展 `GET /lineages`：支持按 `task_uri`（或解析后的 `task_name` + `workflow_name`）过滤，返回该任务的边集合；
- 或新增轻量接口 `GET /b07/lineages/by-task?task_uri=...`，返回去重后的 input/output 表及类型；前端按类型过滤临时表。
- 返回结构统一 `{code,message,data,trace_id}`（沿用 §5.3 信封）。

### 5.5 边界（待复核假设）
- `b04_task` 原有 `input_tables` / `output_tables` 字段**保留**（仍用于导入落库与列表概览），仅「详情页输入输出表清单」以血缘关联结果为准；如确认可弃用原字段，列为后续清理项。

## 6. B04-04 / B03-01 表名点击弹出血缘对话框（受限视图）

### 6.1 功能描述
在 **b04 任务详情页**（输入输出表清单的表名）与 **b03 数据迁移管理**（库表清单的表名）点击任意表名，弹出**对话框**展示该表的血缘**受限视图**：根表固定为被点击的表，页面内**不提供检索栏、不可切换其他表**，仅允许通过节点 `+/−` 与右键菜单上下钻取，节点可右键「查看详情」。

### 6.2 弹层形态（已确认 D4）
- 采用 **Dialog（模态对话框）**：遮罩 `rgba(20,30,45,0.45)`、居中白卡、圆角 `10px`、阴影 `0 16px 48px`、最大宽高 `calc(100vw - 32px)` / `calc(100vh - 48px)`、点击遮罩关闭（`@click.self`），头部标题显示当前表名（对齐 `CODEBUDDY.md` §6.4.6 对话框规范）。

### 6.3 内容（复用 b07 LineageGraph）
- 内嵌 `b07` 的 `LineageGraph` 手写 SVG 组件（节点着色、左→右分层、`+/−` 钻取、右键菜单、节点详情面板、边右键详情、缩放/平移/适应/PNG 导出、图例，均对齐 `血缘管理-数据血缘需求.md` R1~R3 与 §6.4 视觉令牌）。
- **受限约束**（通过组件 props 控制，与 b07 独立页共用同一组件）：
  1. **隐藏检索栏** `SearchBar`（b07 R2）；
  2. **根表固定**：以被点击表为「当前表（聚焦表，绿色描边）」，进入即以其为根**默认展开上游一度**（沿用 b07 R1/R2 默认行为）；
  3. **禁止在弹层内检索/切换其他表**：仅允许节点 `+/−` 与右键菜单（查看详情 / 展开上游全部 / 收起上游 / 展开下游全部 / 收起下游）上下钻取；
  4. **节点右键「查看详情」保留**：右侧浮层展示写入/读取任务（工作流/任务/脚本/项目/类型/对侧表）；边右键详情保留（读写关系与来源任务）。
- 数据：弹层内仍需 `GET /lineages` 取全量边并 `buildGraph` 构图（同 b07 前端），仅根表固定、检索栏隐藏。

### 6.4 与 b07 独立页的关系
- b07 独立页（`space-lineage`）**保持不变**，仍提供完整检索驱动能力；
- 本弹层是其**受限嵌入形态**，二者共用 `LineageGraph` 组件，靠 props 区分「显示检索栏 / 允许根表切换」。

### 6.5 视觉与规范
- 节点：正式表蓝填充 `#e8f0fe`/描边 `#1a73e8`、临时表琥珀 `#fef7e0`/`#f2a100`、聚焦绿描边 `#188038`；上游箭头琥珀 `#c2a36b`、下游蓝 `#1a73e8`；浮层圆角 `10px`、阴影 `0 8px 24px`（对齐 §6.4.2 / §6.4.6）。
- 浮层 z-index 30~60、对话框遮罩 1000（对齐 §6.4.7）。

## 7. 非功能性约束

### 7.1 统一响应与分层（沿用 CODEBUDDY.md §5）
- 接口统一返回 `{ code, message, data, trace_id }`；分页 `{ list, total, page, page_size }`。
- 后端按 router → service → repository → model 分层；跨层用 Pydantic Schema。

### 7.2 界面视觉（沿用 CODEBUDDY.md §6.4）
- 对话框主色 `#1a73e8`、危险红 `#e53935`（如删除场景，本期不涉及）、圆角 `10px`、遮罩 `rgba(20,30,45,0.45)`；血缘节点/连线/浮层语义配色与 b07 一致。

### 7.3 空间隔离与数据归属（沿用既有）
- 血缘数据来自 `mig_<space>_db.b07_lineage`，随空间隔离；弹层取数强制按当前空间过滤。
- `b04_task.dw_project_space` 为源端描述属性，不参与隔离/权限逻辑。
