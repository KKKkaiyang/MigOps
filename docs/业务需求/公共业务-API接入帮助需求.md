## 1. 概述

### 1.1 背景与目标
随着 ak/sk 通用能力（见《公共业务-aksk通用能力与接口开放需求》）落地，b03~b08 已全部支持「登录态 / ak/sk 签名」双鉴权，平台接口可被外部程序（如 skill、自动化脚本）以 REST API 方式调用，用于刷新台账、回写数据校验结果、上传 skill 等自动化场景。

但目前缺少面向开发者的接入指引：用户虽能在个人中心生成 ak/sk，却不清楚如何签名、如何调用、各板块有哪些可用接口。本需求建设**个人中心「API 接入帮助」页**，把接入方式、Python 示例、按板块的场景化接口说明集中呈现，降低对接门槛。

### 1.2 范围
- **涉及前端**：个人中心新增「API 接入帮助」页（**不新建独立菜单**，与「API 密钥」同处个人中心入口区）；页面内嵌 ak/sk 创建指引、Python 通用调用模板、按板块场景化接口说明。
- **涉及后端**：**无新增接口**。帮助内容为前端静态/内置渲染（或聚合既有 `/openapi.json` 展示），不新增服务端能力。
- **涉及库**：无。
- **不在本范围**：Swagger（`/docs`）原始端点列表本身（已存在，本需求仅引用与互补）；b05 数据校验接口的实际开发（二期，本需求仅前瞻列示）。

### 1.3 术语
| 术语 | 含义 |
| --- | --- |
| ak/sk | AccessKey / SecretKey 密钥对，REST API 的 HMAC 签名鉴权凭证 |
| API 接入帮助 | 本次建设的开发者接入指引页面（命名见 D1，不再称「开放平台」以免与对外开放平台混淆） |
| 场景化精选指南 | 按业务板块与典型任务组织的接口说明（含 Python 示例），与 Swagger 完整列表互补 |
| 双鉴权 | 同一接口同时接受「网页登录态」与「ak/sk 签名」两种调用方式（见 AK-02 / BRD §4.5） |

## 3. AH-01 个人中心「API 接入帮助」页

### 3.1 功能描述
在**个人中心**新增「API 接入帮助」入口（与「API 密钥」同区，如侧栏或顶部标签页），点击进入帮助页。帮助页为纯前端页面（或内嵌文档组件），分章节呈现 AH-02 / AH-03 内容。

### 3.2 入口与界面
- **入口**：个人中心内，与「API 密钥」并列；**不新建顶部导航菜单**（契合 §9.9 D2 / 通用能力 AK-01 的不自建菜单原则）。
- **章节结构（建议）**：
  1. 概述：ak/sk 是什么、能做什么（刷新台账 / 回写校验 / skill 上传…）、双鉴权说明；
  2. 创建密钥：引导至「API 密钥」页生成 ak/sk，强调 `secret_key` 仅展示一次；
  3. 鉴权与调用：签名原理 + Python 通用调用模板（AH-02）；
  4. 板块接口说明：b03/b04/b07/b08 场景化指南（AH-03），b05 二期前瞻；
  5. 常见问题（如 401/403 排查）。
- **视觉**：对齐 `CODEBUDDY.md` §6.4 设计令牌（主色 `#1a73e8`、危险红 `#e53935`、对话框/卡片圆角与阴影、代码块等宽字体 `monospace`）。

### 3.3 权限与可用性
- 全部登录用户可见（ak/sk 为通用能力，任何登录用户均可生成并调用）。
- 无后端依赖，无需空间权限即可查看帮助内容。

### 3.4 后端接口
- 无新增接口；帮助页内容由前端内置 / 静态渲染，或聚合既有 `/openapi.json` 展示，不新增服务端逻辑。

## 4. AH-02 ak/sk 创建与鉴权指引 + Python 通用模板

### 4.1 功能描述
帮助页核心章节：讲清如何拿到 ak/sk、如何签名、如何发请求。
- **创建**：步骤说明（个人中心 → API 密钥 → 生成；复制并保存 `secret_key`）。
- **鉴权原理**：双鉴权；ak/sk 签名串 `METHOD\nPATH\nTIMESTAMP\nNONCE`，HMAC-SHA256；时间戳 ±5min、nonce 单次有效（复用 SK-06 / BRD §4.5）。
- **Python 通用模板**：给出可复用的签名函数 + 带签名头的请求封装示例（**仅 Python**，固定约束 D4）。

### 4.2 示例代码（仅 Python）
提供通用 `sign()` 与 `call_api()` 模板，开发者填入 `access_key` / `secret_key` / `path` 即可调用任意 b03~b08 接口。示例强调：`secret_key` 仅客户端保存、不传网络；时间戳为毫秒；头名称 `X-Access-Key` / `X-Timestamp` / `X-Nonce` / `X-Signature`。

### 4.3 后端接口 / 数据
- 无变更；签名校验逻辑已在 `app/services/api_key.py:verify_signature` 实现（AK-02 已落地）。

### 4.4 公共报文规范（请求 / 响应统一约定）

> 本节将「所有接口共有的报文部分」单独抽出，场景化接口（§5）不再内嵌签名、响应信封等细节，仅引用本节约定。

#### 4.4.1 公共请求头
所有 REST API 调用（含 ak/sk 签名）统一携带以下请求头：

| 头名称 | 必填 | 说明 |
| --- | --- | --- |
| `Content-Type` | 是 | `application/json` |
| `Authorization` | 二选一 | 网页登录态：`Bearer <token>` |
| `X-Access-Key` | 二选一 | ak/sk 调用：访问密钥（与 `Authorization` 二选一） |
| `X-Timestamp` | 否* | ak/sk 调用：毫秒时间戳，与 `X-Access-Key` 配套 |
| `X-Nonce` | 否* | ak/sk 调用：单次随机串，与 `X-Access-Key` 配套，单次有效 |
| `X-Signature` | 否* | ak/sk 调用：HMAC-SHA256 签名（签名串见 4.1） |

\* 采用 ak/sk 鉴权时 `X-Timestamp` / `X-Nonce` / `X-Signature` 三项必填（时间戳 ±5min、nonce 单次有效，详见 4.1）。

#### 4.4.2 公共响应信封
所有接口统一返回：
```json
{ "code": 0, "message": "ok", "data": { }, "trace_id": "..." }
```
- `code = 0` 成功；非 0 为业务 / 系统错误码。
- 分页接口 `data` 形如 `{ "list": [], "total": 0, "page": 1, "page_size": 20 }`。

#### 4.4.3 公共错误码
| code | 含义 | 触发场景 |
| --- | --- | --- |
| 40000 | 业务错误（BizError） | 参数 / 业务校验不通过 |
| 40100 | 未认证（UnauthorizedError） | 缺 / 错令牌或 ak/sk 签名校验失败 |
| 40300 | 无权限（ForbiddenError） | 非目标空间成员 / 角色不足 |
| 40400 | 资源不存在（NotFoundError） | 指定 id / 编码不存在 |

## 5. AH-03 按板块场景化接口说明（b03~b08）

### 5.1 功能描述
对 b03/b04/b07/b08（含概念 b06 标签、自定义台账随 b04；b05 二期前瞻）各板块，选取**典型自动化场景**组织精选指南。每个场景先给出一段可复用的 Python 示例（复用 §4.2 通用模板），再以下列**四项**逐接口说明；**不内嵌签名 / 响应等公共报文细节**（统一见 §4.4）：

| 描述项 | 内容 |
| --- | --- |
| 接口名称 | `METHOD /path`（标注 Swagger 路径） |
| 接口说明 | 一句话用途 |
| 接口输入 | path / query / body 参数（字段、类型、必填、说明） |
| 输出参数说明 | 响应 `data` 字段结构（字段、类型、说明）；信封见 §4.4.2 |

### 5.2 板块与场景（精选）

#### 5.2.1 b08 skill — 场景「脚本自动上传 / 下载 skill」
Python 示例：复用 §4.2 `call_api()`，分别调用上传与下载端点。
- **接口名称**：`POST /api/v1/b08/skills`
- **接口说明**：上传 skill（公开 / 私有），供平台内或 REST 方式分发
- **接口输入**：body `{ name, code, version, visibility(public|private), description?, file_url|file }`
- **输出参数说明**：`data` = `{ id, code, name, version, visibility, created_at }`

- **接口名称**：`GET /api/v1/b08/skills/{code}/download`
- **接口说明**：按 code 下载 skill 包
- **接口输入**：path `{ code }`
- **输出参数说明**：文件流（二进制）；失败返回 §4.4.3 错误码

#### 5.2.2 b04 任务迁移（含台账）— 场景「自动刷新 / 更新任务台账」
- **接口名称**：`GET /api/v1/b04/scenarios/{id}/tasks`
- **接口说明**：获取某场景下的任务列表（支持分页 / 筛选）
- **接口输入**：path `{ id }`；query `{ page, page_size, status? }`
- **输出参数说明**：`data` = `{ list:[{ id, task_name, project_name, status, ... }], total, page, page_size }`

- **接口名称**：`POST /api/v1/b04/tasks/{id}/status`
- **接口说明**：更新任务状态（状态流转，需对应角色）
- **接口输入**：path `{ id }`；body `{ status, remark? }`
- **输出参数说明**：`data` = `{ id, status, updated_at }`

- **接口名称**：`PUT /api/v1/b04/tasks/{id}/tags`（b06 标签）
- **接口说明**：为任务打标 / 改标
- **接口输入**：path `{ id }`；body `{ tag_codes: [] }`
- **输出参数说明**：`data` = `{ id, tag_codes: [] }`

> 自定义台账（`/b04/saved-views`）等接口清单见 Swagger（`/docs`）。

#### 5.2.3 b03 数据迁移 — 场景「自动补录迁移过程记录」
- **接口名称**：`POST /api/v1/b03/table-items/{id}/records`
- **接口说明**：为库表清单项补录迁移过程记录
- **接口输入**：path `{ id }`；body `{ stage, content, operator? }`
- **输出参数说明**：`data` = `{ id, table_item_id, stage, content, created_at }`

#### 5.2.4 b07 血缘 — 场景「脚本批量入库血缘」
- **接口名称**：`POST /api/v1/b07/lineages/import`
- **接口说明**：批量导入血缘关系（节点 / 边）
- **接口输入**：body `{ space_id, nodes:[...], edges:[...] }`
- **输出参数说明**：`data` = `{ imported, skipped }`

#### 5.2.5 b05 数据校验（二期前瞻）
本期仅说明：二期将开放校验结果回写接口（如 `POST /api/v1/b05/checks/{id}/result`），用于以 ak/sk 方式回写校验结论；具体输入 / 输出以二期需求与 Swagger 为准，不在此实现。

> 每个板块的完整端点与双鉴权标注（`X-*` 头、401/403）以 Swagger（`/docs`）为权威来源；本帮助页为任务导向精选，不重复罗列全部端点。

### 5.3 空间权限提示
精选指南须提示：b03~b07 为空间隔离业务，ak/sk 操作人须为目标空间成员（D2 / BRD §9.10）；调用需带空间上下文（如 `space_id` 参数），否则返回 `40300`（见 §4.4.3）。

## 6. AH-04 与 Swagger（`/docs`）边界

- 帮助页 = **任务导向精选**，面向「怎么用」；Swagger = **完整接口参考**，面向「每个端点定义」；二者互补，帮助页不重新罗列全部端点（避免维护双份、口径漂移）。
- 帮助页各板块注明「完整接口见 Swagger（`/docs`）」，并说明 b03/b04/b07 端点已在 Swagger 标注双鉴权（`X-*` 头与 401/403）。

## 7. 非功能性约束

### 7.1 统一响应与分层（沿用 CODEBUDDY.md §5）
- 接口统一 `{ code, message, data, trace_id }`；分页 `{ list, total, page, page_size }`；帮助页本身不调用业务接口（除可选聚合 openapi）。

### 7.2 界面视觉（沿用 CODEBUDDY.md §6.4）
- 主色 `#1a73e8`、危险红 `#e53935`、圆角 / 阴影 / 等宽代码块令牌；状态 / 类型采用「颜色编码 + 文字标签」双标识。

### 7.3 内容维护
- 帮助页场景示例与接口清单应随接口演进同步更新；建议示例以独立文件 / 常量维护，便于复用与校验（示例语言仅 Python，D4）。
